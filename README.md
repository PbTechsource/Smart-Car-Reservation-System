# 🚗 Smart Car Reservation System

Developed by **Tech Source Group**

A Python-based vehicle reservation and inventory management system with admin and user dashboards, reservation tracking, search functionality, and data visualization using Matplotlib.

---

## 📌 Project Overview

The system contains two separate dashboards:

### 👤 User Panel

Users can:

- Login and Logout
- Search available vehicles
- Add vehicles to reservation cart
- Reserve vehicles
- View their reservations

### 👨‍💼 Admin Panel

Administrators can:

- Login and Logout
- Add new vehicles
- Edit vehicle information
- Increase or decrease inventory
- Monitor reservations
- Manage vehicle availability
